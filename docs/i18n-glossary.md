# i18n glossary (English source ↔ Simplified Chinese)

Use these exact terms so the Mac app, the web page and the server read as one product.
English: concise, macOS style, sentence case for labels and buttons ("Open board", "Mark all read").
Avoid singular/plural agreement problems ("1 tasks"): prefer forms that read right for any
number, e.g. "Running 2", "2 running", "Waiting: 3".
